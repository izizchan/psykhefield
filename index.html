内容説明

開発中のバーチャロンライクな操作感のマルチプレイ対戦ゲーム

サーバーの特徴:
  - サーバーで全ての物理判定処理を行う
  - 通信状態をみてプレイヤーが近づける距離を制限
  - ロールバック処理で高レスポンスを実現

ゲームの特徴:
  - ブーストゲージによる速度調整
  - ロックオンボタン＋ダッシュ攻撃時の自動ロックオン
  - 被ロックオン状態の表示
  - ガード＋攻撃による近接モード切替
  - 爆風の自爆、味方攻撃アリ

ゲームルール（サーバー側で設定）:
  - エンドレス バトルロワイヤル: 最大連続破壊数の記録モード
  - チーム戦: COOP/PvP/PvPvE チーム人数×3の連続勝利数合計を先に取ったチームの勝利

SE,ロボットモデル,ステージ配置やギミックは仮設状態です。
今後VRM形式の読込みなどを付けていく予定ですが、
遊ぶためのゲーム部分を先に開発しています。

description

A multiplayer combat game currently in development with a “Virtual-On”-like control scheme

Server Features:
  - All physics calculations are handled by the server
  - Limits the distance players can approach each other based on network conditions
  - Achieves high responsiveness through rollback processing

Game Features:
  - Speed control via a boost gauge
  - Auto-lock-on when using the lock-on button + dash attack
  - Display of locked-on status
  - Switch between close-range and long-range modes by guarding and attacking
  - Explosions can cause self-destruction and damage allies

Game Rules (Set on the server side):
  - Endless Battle Royale: A record-breaking mode for the highest consecutive destruction count
  - Team Battle: COOP/PvP/PvPvE The first team to reach a total of (team size × 3) consecutive victories wins

Sound effects, robot models, stage layouts, and mechanics are currently in a provisional state.
We plan to add VRM file import support in the future,
but we are prioritizing the development of the core gameplay first.
